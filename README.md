Study Café ☕️

Study Café is a full-stack student task management app built to make keeping track of college work a little more enjoyable.

You can create, edit, delete and complete tasks, set priorities and due dates, and view tasks based on their status or date. The app also has a day/night theme, a short break timer, and a few mini-games to play during breaks.

Tech Stack
Next.js + React + TypeScript
Next.js API Routes
PostgreSQL (Neon)
